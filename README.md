# Coffee Report

CLI-скрипт для обработки CSV-файлов с данными о подготовке студентов к экзаменам.

Скрипт поддерживает отчёт `median-coffee`, в котором для каждого студента рассчитывается медианная сумма трат на кофе по колонке `coffee_spent` по всем переданным файлам. Результат выводится в консоль в виде таблицы и сортируется по убыванию значения.

Примеры входных CSV-файлов находятся в папке `examples/`.

## Пример запуска

```bash
python -m coffee_report.main --files examples/math.csv examples/physics.csv examples/programming.csv --report median-coffee
```
